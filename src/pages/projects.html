Inference engine

Larch engine

The engine. It serves open models from the GPU already on your desk, and nothing leaves the machine unless you send it.

Runs on
Apple silicon · NVIDIA RTX 30, 40 and 50
Models
Llama 3 · Qwen 2.5, 3 and 3.5 · Mistral
Serves
/v1/chat/completions · /v1/messages
Checked
Same top token as llama.cpp, 99 % of the time or better
Measured results larch-engine.com

  • Many chats, one card

    Conversations share each step on the GPU, so one card serves sixteen at once.

  • Picks up where you left off

    A finished conversation is parked, and the next turn starts from its saved state.

  • Works with your tools

    Claude Code, Qwen Code and OpenCode connect to it on localhost.

  • Recovers on its own

    Run under larch supervise, it restarts after a GPU fault and the chat resumes where it stopped.

Personal agent

Larch

The agent. It lives on your computer and knows the difference between reading and spending.

Runs on
The Larch engine, on your own machine
Skills
ask_docs · web_answer · read_papers · research
Connects
As an MCP server, for your other tools
Measured
Wrong tool 2.5 % of the time with Qwen3-8B

  • Asks before it spends

    Spending always asks first, and after anything untrusted, so does every write.

  • Shows its sources

    Quotes your documents by file and line, and the web only where the saved page still says it.

  • Memory you can read

    Plain text files you can open, edit and delete, each change logged with its reason.

  • Stays on the machine

    Other tools can use it, but it never offers them spending or writes beyond this computer.
